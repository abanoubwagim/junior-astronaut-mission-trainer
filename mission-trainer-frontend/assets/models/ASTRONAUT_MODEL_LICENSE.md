## Animation contents

The GLB contains a humanoid skeleton and the following clips:

- `walk`
- `run`

MoonBase maps those clips to lunar walking and loping. Idle, jump, airborne,
landing, interaction, pointing, reacting, celebrating, and disappointed states
use the same skeleton with documented rig-bone poses when the source asset does
not provide a dedicated clip. The old Three.js Soldier model is not used.
